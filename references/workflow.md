# 工作流完整规范（6 步 + 收尾）

## 阶段 A：准备

### 第 1 步 工具与工作目录

- 读取环境说明，取真实路径（见 `environment.md`），运行 `check_env.py` 一次。
- 用 `init_task.py` 建 TASK（含 media/、asr/）与 manifest.json。
- 匹配视频 ID + 媒体来源 + 时长的缓存直接复用，manifest 标记来源，不冒称本次识别。
- 交接条件：得到真实工具路径与 TASK。命令报错才修缺项一次，不重复安装、跑分或全盘搜索。

### 第 2 步 Web Access（仅链接任务）

- 复用已有 Proxy 与 Chrome 登录态，不逐步骤重复检查、不重启浏览器/Proxy、不切账号。
- 需要本人调试授权/登录/验证码时，报告实际页面与必要动作，等用户完成后再接。
- 保留用户原有标签页。
- 交接条件：同一常规 Chrome 中的目标视频页可读取。

## 阶段 B：取媒体

### 第 3 步 身份解析与取址

- 从分享文案提取链接，在 Chrome 跟随跳转，保存最终 URL 与真实视频 ID。
- **不能只凭标题判断**：用页面内数据（描述、note.noteId、bvid 等）确认是目标视频。
- 读取播放器和页面数据要立即执行；未就绪时每 0.5–1 秒轮询，默认最多观察 15 秒，出现即继续，不固定空等。
- 取址顺序（成功即停）：
  - A：`/eval` 读 video 元素 currentSrc / src / source，只有 http(s) 可交给下载器。适配器 `douyin.js` / `generic.js`。
  - B：只有 blob: 或空地址时，读页面已公开加载的初始化 JSON：小红书 `__INITIAL_STATE__`、B站 `__playinfo__`。适配器 `xiaohongshu.js` / `bilibili.js`。字段不存在就按当前结构解析，不把示例字段当固定接口。
  - C：仍无地址，读 `performance.getEntriesByType("resource")` 的实际资源 URL，结合播放器、视频 ID、时长确认对应。只采用本次目标实际加载的资源。适配器 `generic.js`（未实测，需人工确认）。
- 禁止：blob: 直传给 requests/curl/FFmpeg；改造签名参数；研究 a_bogus；随意拿第一个视频域名地址。
- 只有明确未加载才刷新同页一次；刷新后仍拿不到就记录卡点，不换浏览器、不全程播放录音。
- 交接条件：manifest 保存对应目标的页面 URL、视频 ID、时长与可用媒体地址。

### 第 4 步 下载与核验

- 优先下载独立完整音轨；没有就下载带声音的视频。保留媒体 URL 原有参数。
- 用 `download.py`：同页 UA + Referer，分块写入；不打印二进制或完整 URL；不读取账号 Cookie/密码。
- 401/403：只回同页刷新媒体地址一次、再试一次；仍失败就报告，不连续换接口。
- 用 `probe.py` 执行 ffprobe：结果可解析、有 audio 流、时长与目标相符。只有视频流没有音频时改用完整音轨；分片/预览不能当完整音轨。
- 交接条件：得到可读取、时长匹配的本地完整有声媒体，manifest 标记下载完成。

## 阶段 C：转写交付

### 第 5 步 FFmpeg 提音与本地 ASR

- 顺序：FFmpeg 16kHz 单声道提音 → FSMN-VAD 分段 → Paraformer → CT-punc → TXT/JSON（SRT 强制产出但忽略）。
- 用发布版 `scripts/transcribe.py`，接口 `<媒体> -o <前缀> [--asr-only] [--models-dir] [--ffmpeg]`。脚本内部已提音，不要再在外面转 WAV。
- 调用时加 `PYTHONDONTWRITEBYTECODE=1`（双重保险）。等待时看进程与现有日志，不重复启动。
- 核对：段数全部非空、末段 end 与媒体时长吻合（允许尾部静音差）。失败片段只重试一次，仍失败明确标注缺口。
- 交接条件：完整音频处理结束，取得原始 TXT/JSON。

### 第 6 步 校正与输出

- 完整通读原始稿一次，只修正有依据的错字、同音误识别和标点；保留原话、语气词、重复、自我修正，不改写或缩短。
- 明显影响理解的疑点最多局部复核一次；不能确认就标注 `[听不清，时间点]`，不多次切窗口求共识。
- 检查无截断、无失败片段静默漏掉，保存 UTF-8 校对 TXT。无须改动直接采用原稿。
- 对话中直接输出完整校对稿，按语义分段，正文无时间戳（疑点标记除外）；太长就连续分段输出，再给路径。
- 交叉核对服务可用时可选一次，短超时失败即降级，不反复重试。

## 收尾

- 用 `cdp.py close <targetId>` 只关闭自己创建的页面，保留 Proxy 和用户页面。
- 复用缓存时说明来源。
- 记录页面、下载、ASR（含加载）、校对实际耗时，无法拆分就合并注明。
- 最后只附一行耗时和真实缺项。完成即交付，不反复"最终检查"。
